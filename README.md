# online-retail-data-analytics.
End-to-end online retail data analytics project using Python, MySQL, Power BI, and DAX.
Online Retail Data Analytics Project
📊 Project Overview

This project analyzes an online retail dataset to understand sales, orders, customers, products, and countries.

The project uses:

Excel → Python → MySQL → Power BI

🛠️ Tools Used
Excel
Python
Jupyter Notebook
MySQL 8
Power BI
DAX
GitHub
🔍 What I Did
Loaded and inspected the retail dataset
Checked missing values and data quality
Identified cancellations and unusual transactions
Cleaned the data using MySQL
Created an analysis-ready table
Created DAX measures in Power BI
Built an interactive sales dashboard
📈 Power BI Dashboard

The dashboard includes:

Total Revenue
Total Quantity
Total Orders
Total Customers
Average Order Value
Revenue by Month
Top 10 Countries by Revenue
Top 10 Products by Revenue
Top 10 Countries by Orders
Top 10 Countries by Quantity
Country and Date filters
